📖 먹자 사용 가이드

  1. 가게 고르기 왼쪽 위 ☰를 눌러 커피·점심 가게를 선택해요.
  2. 팀 선택 상단 팀 버튼에서 본인 팀을 골라요. 현재 팀은 우측 상단 세션 표시로 확인할 수 있어요.
  3. 주문자 선택 이름 알약을 좌우로 넘겨 고르거나, 기타로 직접 입력해요.
  4. 메뉴 담기 메뉴를 누르고 옵션(온도·얼음·샷 등)을 고른 뒤 담기 → 하단 주문하기를 눌러요.
  5. 1인 1메뉴 새로 담으면 기존 선택이 바뀌어요. 이미 주문했다면 주문 취소가 떠요.
  6. 집계 보기 상단 집계에서 메뉴별·사람별 합계와 미주문자를 확인해요. 요약 복사·(점심) 전화하기도 여기 있어요.
  7. 마감·초기화 당번이 집계 화면에서 마감 시각을 정하면 이후 주문이 막혀요(빨간 마감). 매일 자정에 자동 초기화돼요.
